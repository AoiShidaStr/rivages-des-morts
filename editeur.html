Commandes

ClicChoisir un élément (le plus proche devant). Un clic dans une zone la sélectionne.
GlisserDéplacer l'élément, un sommet de zone, ou une zone déjà sélectionnée tout entière. Dans le vide : déplacer la vue.
Clic droit / molette enfoncée / Espace + glisserDéplacer la vue
MoletteZoomer
Double-clic sur un bordAjouter un sommet à la zone sélectionnée
SupprSupprimer le sommet choisi, sinon l'élément (les PNJ se déplacent mais ne se suppriment pas)
Ctrl+DDupliquer (décor, bâtiment, zone)
FRetourner le décor
+ / -Agrandir / rétrécir le décor ou le bâtiment
FlèchesPousser l'élément de 0,1 (avec Maj : 1)
PaletteChoisis une image puis clique sur la carte pour la poser, autant de fois que tu veux. Échap pour arrêter.
+ Zone…Clique les sommets un à un ; Entrée, double-clic ou clic sur le premier point pour fermer ; Retour arrière enlève le dernier.
Ctrl+Z / Ctrl+YAnnuler / rétablir
Ctrl+SEnregistrer dans src/data/island.json : le jeu ouvert se recharge tout seul.

Le héros ne marche que dans les zones vertes, moins les obstacles rouges et les cercles de collision des objets. Une zone de marche trop étroite (moins de 0,7 de large) ne laisse pas passer le héros.

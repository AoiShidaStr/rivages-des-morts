## Nouveautés

- Bouton **Nouveautés** sur l'écran titre : les changements de chaque version, à lire sans quitter le jeu. Un point le signale tant que tu n'as pas lu la dernière.
- La version du jeu est rappelée en bas de l'écran titre.

## Déjà arrivé ces derniers jours

- **Coop en ligne** jusqu'à 3 joueurs : salon, code d'invitation et liste des parties publiques.
- **Plusieurs personnages** : jusqu'à 6, avec export et import d'un fichier de sauvegarde.
- **Le moine du Rocher** te fait changer de race ou de classe, gratuitement.
- **Héros peints** : animations dédiées pour le Demi-dieu, le Hanyō et le Rôdeur Einherjar.
- **Équilibrage** des classes et des races : Paladin tank-soutien, un soin par classe, affinités de race, compagnon de l'Invocateur. Le premier donjon est passable avec toutes les classes, et la première victoire donne une arme de ta classe.
- **Retour de coup** : micro-pause à l'impact, entrées mémorisées.

## Corrections

- La visée tombe exactement sous le curseur sur les écrans zoomés (125 %, 150 %, Retina).
- Tir chargé du Rôdeur : lâché aussitôt, il ne fait plus que 0,2 fois les dégâts.
- Écran de fin : la liste du butin défile, les boutons restent visibles.

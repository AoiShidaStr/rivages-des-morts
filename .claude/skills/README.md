# Skills du projet

Skills Claude Code chargés automatiquement dans ce dépôt. Ce sont des fichiers texte (et quelques scripts Python locaux) ; **aucun hook ni script ne s'exécute tout seul**.

| Skill | Source | Licence | Rôle |
|---|---|---|---|
| `webapp-testing` | [anthropics/skills](https://github.com/anthropics/skills) (dbd4588, 09/10/2026) | Apache 2.0 (`LICENSE.txt`) | Lancer le jeu dans Chromium, capturer, lire la console avant d'annoncer un changement. Notes propres au jeu à la fin du `SKILL.md`. |
| `skill-creator` | [anthropics/skills](https://github.com/anthropics/skills) (dbd4588) | Apache 2.0 (`LICENSE.txt`) | Écrire nos propres skills (règles des planches, des sons, de l'équilibrage). |
| `systematic-debugging` | [obra/superpowers](https://github.com/obra/superpowers) (bb92a77, 09/10/2026) | MIT (`LICENSE`) | Trouver la cause d'un bug avant de corriger. Fichiers de test internes du paquet retirés. |
| `writing-plans` | [obra/superpowers](https://github.com/obra/superpowers) (bb92a77) | MIT (`LICENSE`) | Découper un chantier en petites étapes vérifiables. |

Pour mettre à jour un skill : recopier son dossier depuis le dépôt source et relire le diff.

Les idées tirées de Claude Code Game Studios sont rangées à part, dans `docs/idees/claude-code-game-studios/`, pour qu'elles ne se chargent pas automatiquement.
